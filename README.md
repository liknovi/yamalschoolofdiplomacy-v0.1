# Ямальская школа дипломатии — анонсный сайт

Статический адаптивный сайт для публикации через GitHub Pages. Сейчас это промо-страница: анкета намеренно не подключена.

## Запуск локально
Откройте `index.html` в браузере. Для локального сервера можно использовать расширение Live Server в VS Code.

## Публикация через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `script.js`, `README.md` и папку `assets` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. Через несколько минут сайт появится по адресу GitHub Pages, который покажет GitHub в этом разделе.

## Настройки
- Дата начала приёма заявок настраивается в `script.js` в переменной `target`.
- Тексты и ссылки меняются в `index.html`.
- Цвета, композиция и адаптивность находятся в `style.css`.
- Шрифт Onest подключён через Google Fonts; для загрузки шрифта браузеру нужен интернет.

## Перед публичным запуском
- Подтвердите точное время открытия приёма заявок. Сейчас таймер настроен на 00:00 1 февраля 2027 по UTC+5 (время ЯНАО).
- Проверьте актуальность официальных ссылок и формулировок.
- Логотипы взяты из предоставленного архива.
- Форма заявок не реализована намеренно и должна быть добавлена отдельно к старту отбора.
